# عطاء (Ata'a)

**عطاء** is a basic Arabic, RTL charity and volunteering platform that I redesigned and rebuilt as a personal UI/UX and front-end project.

The project began as an effort to replicate and improve a friend's work. I then used the opportunity to redesign the experience from the ground up, focusing on clearer navigation, responsive layouts, visual hierarchy, and engaging interactions. I self-learned Figma to create a high-fidelity prototype and developed the resulting interface without prior formal design experience.

## Highlights

- Arabic-first, right-to-left user interface
- Fully responsive layout for desktop, tablet, and mobile screens
- Charity campaign browsing with search and category/city filters
- Donation flow with campaign, amount, and payment-method selection
- Volunteer discovery, search, and sign-up experience
- Events and volunteering activity sections
- User authentication, registration, and profile views
- Interactive hover states, transitions, loading states, notifications, and page animations
- Community-focused dashboard content for donations, volunteers, events, and beneficiaries

## Design process

1. Studied and evaluated the original concept.
2. Identified opportunities to improve usability, consistency, and visual appeal.
3. Self-learned Figma and created a high-fidelity, responsive prototype.
4. Rebuilt the interface as a working front-end prototype while adding responsive behavior and interaction details.

## Running locally

This is a static front-end project. Open `index.html` in a browser, or serve the repository with any local static server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Note

This repository is a front-end prototype for demonstrating the redesigned experience. It does not include a production backend, persistent database, or live payment processing.
